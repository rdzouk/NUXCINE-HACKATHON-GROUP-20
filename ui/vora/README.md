# Vora UI mock

Maquette responsive de l'interface Vora (VTC) fournie en HTML/CSS/JS.

Exécution locale

1. Ouvre le dossier `ui/vora/`.
2. Double-clique sur `index.html` pour ouvrir la maquette dans ton navigateur.

Notes

- Le fond de la "carte" est un placeholder (image Unsplash). Pour utiliser une vraie carte, intègre Mapbox/Leaflet/Google Maps et remplace `.map-bg`.
- Palette : variables CSS dans `styles.css` (--accent / --accent-2) pour ajuster le vert néon.
- Assets : remplace les avatars et images par tes propres fichiers.

Prochaines étapes possibles

- Intégrer Mapbox et tracer un itinéraire réel.
- Convertir la maquette en Flutter / React Native pour mobile.
- Ajouter interactions (sélection d'options, calcul de prix, etc.).
